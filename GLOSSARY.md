# Календарь звонков

Сервис, через который гости записываются на звонок с владельцем календаря.

## Участники

**Владелец**:
Единственный человек, на чьё время записываются гости. Заводит типы встреч.
_Избегаем_: хост, админ, организатор
_По-английски_: owner

**Гость**:
Человек, который записывается на встречу без регистрации, оставляя имя и email.
_Избегаем_: клиент, пользователь, посетитель
_По-английски_: guest

## Запись

**Тип встречи**:
Вид встречи, который предлагает владелец: название, необязательное описание и длительность.
_Избегаем_: услуга, шаблон, событие
_По-английски_: meeting type, не event type

**Встреча**:
Время в календаре владельца, которое гость занял под конкретный тип встречи.
_Избегаем_: бронь, запись, событие
_По-английски_: meeting, не booking, appointment, event

**Предстоящая встреча**:
Встреча, которая ещё не закончилась.
_Избегаем_: будущая встреча, активная встреча
_По-английски_: upcoming meeting

**Записаться**:
Выбрать тип встречи и слот и оставить имя и email. В результате появляется встреча.
_Избегаем_: забронировать

**Конфликт**:
Отказ в записи, потому что время пересекается с уже существующей встречей.
_Избегаем_: коллизия, двойная бронь, занятый слот
_По-английски_: conflict

**Слот**:
Свободный отрезок времени длиной в тип встречи, с которого может начаться встреча. Начинается на шаге стартов и целиком лежит в рабочих часах.
_Избегаем_: окно, таймслот
_По-английски_: slot

**Шаг стартов**:
Промежуток между соседними возможными началами слотов, один для всех типов встреч.
_Избегаем_: сетка, интервал слотов
_По-английски_: slot step

**Окно записи**:
14 календарных дней начиная с завтрашнего, внутри которых гость может записаться.
_Избегаем_: период, горизонт
_По-английски_: booking window

**Рабочие часы**:
Дни недели и часы, в которые владелец принимает встречи. Слоты бывают только внутри них.
_Избегаем_: график, расписание, доступность
_По-английски_: working hours

## Страницы

**Главная страница**:
Первая страница гостя: что это за сервис и как записаться.
_Избегаем_: лендинг, стартовая

**Каталог типов встреч**:
Страница, где гость выбирает тип встречи. С неё начинается запись.
_Избегаем_: страница записи, список услуг

**Страницы владельца**:
Страницы, где владелец заводит типы встреч и смотрит предстоящие встречи. Входа нет, открыть их может любой.
_Избегаем_: админка, админская часть, личный кабинет
