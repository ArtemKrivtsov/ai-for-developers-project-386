# Фронтенд — SPA без серверного рендеринга

Фронтенд — SPA на React Router в режиме библиотеки, без SSR. Страницы не нужно индексировать, а бэкенд уже есть на Fastify, поэтому framework mode с отдельным сервером рендеринга не берём. Следствие: в продакшене сервер отдаёт `index.html` на любой адрес, кроме `/api`.
