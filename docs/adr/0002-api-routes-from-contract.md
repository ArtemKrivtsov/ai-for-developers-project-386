# Маршруты API строятся из контракта во время работы

API описан контрактом на TypeSpec. Fastify строит маршруты и валидацию запросов во время работы из сгенерированного OpenAPI через fastify-openapi-glue, обработчики типизированы сгенерированным `RouteHandlers`. Альтернативу (писать маршруты и схемы вручную и сверять их с контрактом тестами) отвергли: расхождение сервера с контрактом всплывало бы позже, а так его ловит typecheck.
