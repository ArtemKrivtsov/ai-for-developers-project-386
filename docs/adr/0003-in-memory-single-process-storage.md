# Данные хранятся в памяти одного процесса

Типы встреч и встречи живут в памяти процесса и пропадают при перезапуске, стартовые типы создаются заново. Хекслет не требует сохранять данные и запускает один контейнер без базы, а тесты получают чистое хранилище без схемы и файлов. SQLite через встроенный `node:sqlite` отвергли: он добавляет схему, путь к файлу и том, а выгоды для проверки нет. Следствие: запись проверяет слот и сохраняет встречу одной синхронной функцией без `await` между шагами, и только поэтому одновременные запросы не создают пересекающихся встреч. Приложение запускается одним процессом. Cluster или несколько копий сломают это правило, поэтому перед масштабированием хранилище нужно заменить.
